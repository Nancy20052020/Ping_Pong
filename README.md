# Ping Pong

A two-player Pong game written with Python's `turtle` module.

## Requirements

- Python 3
- Tk, which `turtle` uses for the window

## Run

```bash
python pong.py
```

## Controls

- Left paddle: `W` and `S`
- Right paddle: Up and Down

The ball speeds up after each paddle hit. A point is scored when the ball passes a paddle.
